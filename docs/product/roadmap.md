# Roadmap

## Now

- Keep Markdown-to-published-post flow reliable.
- Improve reading quality, navigation, and discoverability without adding publishing complexity.
- Keep static builds, linting, and typechecking trustworthy.

## Next

- Maintain a small, explicit bridge between the Obsidian ideas pipeline and `posts/`.
- Improve blog metadata and sharing only when it measurably helps readers find useful posts.

## Later / investigate

- Search or topic navigation if the post collection becomes difficult to browse.
- Lightweight feedback or distribution mechanisms if there is a clear reader need.

## Explicitly not planned without evidence

- A CMS replacing Markdown
- Accounts, comments, or social features
- A complex editorial workflow for a single-author blog
- Content sections that exist only because a template offers them
